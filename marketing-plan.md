# Plan SEM, SEO et GEO

Objectif: atteindre environ 1 conversion par jour avec un cout d'acquisition bas.

## Economie cible

Si la prime est de 40$, le cout maximal par conversion doit rester nettement sous 40$ pour que le projet soit rentable. Une cible prudente:

- CPA ideal: 3$ a 8$.
- CPA acceptable en test: 8$ a 15$.
- CPA a couper: plus de 18$ pendant plusieurs jours sans signe d'amelioration.

Le projet doit d'abord mesurer les clics sortants et les copies du code. La conversion Fizz finale ne sera pas toujours visible si Fizz ne fournit pas de suivi d'affiliation.

## SEO

Pages a creer apres la landing page:

- `/code-reference-fizz/`: intention directe.
- `/code-promo-fizz/`: capter les recherches de rabais, avec transparence sur le fait qu'il s'agit d'un code de reference.
- `/fizz-mobile-quebec/`: page informative pour les forfaits mobiles au Quebec.
- `/fizz-internet-residentiel/`: page informative pour Internet residentiel.
- `/comment-utiliser-code-reference-fizz/`: guide et FAQ.

Principes:

- Repondre vite a l'intention: le code visible haut dans la page.
- Garder une FAQ claire pour les extraits enrichis.
- Mentionner les conditions: premier forfait, deux mois de service, montant sujet a changement.
- Eviter les affirmations non verifiees comme `meilleur forfait` sans comparaison solide.
- Ajouter une date de verification visible sur les pages de contenu.

## SEM

Commencer petit, avec des mots-cles exacts ou expression exacte.

Groupes d'annonces:

- Code direct: `code reference fizz`, `code promo fizz`, `rabais fizz`, `prime reference fizz`.
- Mobile: `forfait mobile fizz`, `fizz mobile quebec`, `fizz sim`.
- Internet: `internet fizz`, `fizz internet residentiel`, `forfait internet fizz`.

Negatifs a ajouter:

- `emploi`
- `service client`
- `plainte`
- `panne`
- `connexion`
- `telephone fizz support`
- `reddit` si le trafic ne convertit pas

Structure de test:

- Budget initial: 3$ a 5$ par jour.
- Arret rapide des mots-cles sans clic qualifie.
- Garder seulement les termes avec intention d'abonnement ou de code.
- Ne pas miser sur `Fizz` seul au debut: trop large, probablement cher et moins qualifie.

Exemple d'annonce sobre:

Titre: `Code de reference Fizz 40$`

Description: `Copiez un code de reference Fizz avant d'activer votre premier forfait. Site independant. Conditions Fizz applicables.`

## GEO

Ici, GEO couvre deux axes: geociblage local et optimisation pour les moteurs generatifs.

Geociblage:

- Cibler Quebec d'abord si ton offre Fizz est surtout pertinente la.
- Ajouter Montreal, Laval, Longueuil, Quebec, Gatineau et Sherbrooke dans les pages de contenu si tu peux offrir une information utile, pas seulement une liste de villes.
- Adapter les requetes autour de `forfait mobile Quebec`, `internet residentiel Quebec`, `Fizz Montreal`.

Optimisation generative:

- Creer des reponses courtes et factuelles dans les FAQ.
- Citer les sources officielles Fizz.
- Garder une page `a propos` claire: site independant, objectif, date de verification.
- Eviter le contenu gonfle. Les moteurs generatifs preferent souvent les pages utiles, directes et faciles a citer.

## Mesure

Evenements a suivre:

- Clic sur le bouton vers Fizz.
- Copie du code.
- Clic sur les conditions Fizz.

Outils possibles:

- Google Search Console pour SEO.
- Bing Webmaster Tools pour SEO.
- Plausible, Fathom ou Google Analytics pour les evenements.
- Microsoft Clarity pour voir si les visiteurs trouvent le code.

## Cadence des 30 premiers jours

Semaine 1:

- Publier la landing page.
- Connecter Search Console.
- Lancer 1 campagne SEM avec budget faible.
- Ajouter les mots-cles negatifs des premiers termes de recherche.

Semaine 2:

- Creer 2 pages SEO: code de reference et guide d'utilisation.
- Tester deux variantes de titre SEM.
- Verifier si les clics sortants augmentent.

Semaine 3:

- Creer 2 pages comparatives informatives mobile et Internet.
- Ajouter une page a propos et une note de transparence.
- Couper les mots-cles trop chers.

Semaine 4:

- Consolider autour des pages qui recoivent impressions ou clics.
- Ajouter une FAQ enrichie selon les vraies questions.
- Decider si le budget SEM merite d'etre augmente.

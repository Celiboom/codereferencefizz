Comment utiliser un code de référence Fizz?

Copiez le code, démarrez l'activation de votre premier forfait Fizz, puis entrez le code dans le champ de référence avant de soumettre la commande.

Est-ce un site officiel Fizz?

Non. ProjetFZ est un site indépendant qui partage un code de référence Fizz. Les conditions finales sont toujours celles affichées par Fizz.

Le bonus est-il appliqué sur la première facture?

Fizz indique que la prime est généralement appliquée après que le nouveau membre a cumulé deux mois de service admissible. Ce n'est donc pas toujours un rabais immédiat.

Puis-je ajouter un code après mon inscription?

Fizz indique que le code doit être entré lors de l'activation du premier forfait; il ne peut généralement pas être ajouté rétroactivement.

Le code fonctionne-t-il pour mobile et Internet?

Le programme de référence Fizz peut s'appliquer à un premier forfait admissible. Vérifiez toujours les conditions affichées par Fizz avant de finaliser.

Le montant de 25$ est-il garanti?

Non. Le montant peut changer sans préavis selon les conditions Fizz. Cette page indique la valeur observée au moment de la dernière vérification.

Pourquoi le code est-il aussi dans le lien?

Le lien ajoute le paramètre de référence pour faciliter le parcours, mais gardez quand même le code copié afin de pouvoir le coller si Fizz vous le demande pendant l'activation.
